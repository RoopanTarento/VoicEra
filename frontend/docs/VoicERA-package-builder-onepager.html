VoicERA for government · Package builder experience · One-pager

Describe it. Build it. See if it fits.

A set of connected screens that help a government department work out, without a meeting, whether the VoicEra Fully Loaded (Platinum) package fits its idea, what it costs, and what to bring. Four ways in, one rules engine underneath.

How it works underneath

What you give itBlocks, one sentence, or answers. Anything you do not say stays unknown, never assumed.
→
One rules engine14 checks against the package document: use case, direction, call length, languages, knowledge base, telephony, integration, capacity, campaigns, hosting, data, cost, readiness, open items.
→
What you get backOne of four verdicts, the reason, what to remove, a checklist, a plan, a cost, and exports.

What the adopter gets

  • A straight answer: suitable, suitable with conditions, needs review, or outside scope. It never forces a yes.
  • The reason, with a source for every limit: 500 calls, 3 minutes, 10 files of 5 MB, 11 languages.
  • What would make it fit when it does not, re-checked by the same rules.
  • What to bring: script, knowledge base, phone list, permission, test callers, approvals.
  • A cost from documented rates: ₹50,000 setup, ₹500 a number, ₹0.50 a minute. Proprietary pricing stays "not supplied".
  • Something to hear and download: a conversation to play, a script, knowledge files, a zip.

What is real, what is a demo

  • Real: the rules, the limits, the prices, the checklist logic and the exports. They run in your browser.
  • Demo: the conversation is a text simulation. No speech, model or telephony, and nobody is called.
  • Rule-based reading: one-sentence input uses keyword rules. No AI service is connected.
  • Nothing is sent: "request an implementation discussion" only prepares text on your device.
  • Saved locally: answers stay in this browser only.

Still open in the package document

  • Where call data is stored, whether it trains models, how long it is kept
  • The actual model list and quality, and proprietary-model pricing

Try it in two minutes

  1. Open the Composer. Pick "Scheme helpline".
  2. Drag in "Check a citizen's record". Watch it turn red.
  3. Click "Remove it". The verdict recovers.
  4. Open "Hear it". Play the conversation.
  5. Open the full recommendation. See the report and cost.
  6. Want the proof of concept? Use the Scheme Discovery builder.
  • Run it: cd frontend && npm run dev, then open localhost:3000/adopt/all for every screen. Test it: npm run test:advisor. Existing screens (discover, workspace, 11-step path) are unchanged.
